アプリシェル

このページ全体がシェルのライブデモです。左サイドバー（折りたたみ可）+ トップバー（テナント切替 / テーマ / ロール / ユーザーメニュー）。

サイドバー
ダッシュボード / デバイス / ポリシー / エンロール / アプリ / 監査ログ / 管理者（tenant-console）。管理者は TenantAdmin 以上で表示（アクセス不可は非表示）。「テナント」は admin-console 側のため本シェルには含めません。
トップバー
ページタイトル・現在ユーザー（email + ロールバッジ）・ユーザーメニュー。自テナント固定（テナント切替は持たない）。ロールを切替えると操作・ナビ表示が変化します。
レスポンシブ
サイドバー左下のボタンで 240px ⇄ 64px に折りたたみ。狭幅ビューポートでは自動でアイコンのみ表示に。
