admin-console シェル・リファレンス

SaaS 運用者（SuperAdmin）が顧客テナントそのものを管理する運用コンソール。tenant-console とは別アプリ・別 OIDC クライアントですが、同一のデザイン言語（トークン・共通コンポーネント）を共有します。backend は同一で /api/admin 系を叩きます。

ADMIN バッジでアプリを識別
横断が前提（テナント切替なし）
トークン・部品は tenant-console と共通

ナビゲーション

左サイドバーの項目は 4 つ。tenant-console の業務ナビ（デバイス/ポリシー等）は持たず、プラットフォーム運用に特化します。

テナント
顧客テナントの一覧・作成・Enterprise バインド・無効化。/tenants
横断ダッシュボード
全テナント横断の稼働・コンプライアンス・容量サマリ。/overview
未割当（退避キュー）
テナント未割当・バインド未完了などで退避中の端末/リソース。件数バッジで滞留を可視化。/unassigned
横断監査ログ
全テナント横断の監査ログ（テナント列つき・追記専用）。/audit

トップバー

ページタイトル + 現在ユーザー（SuperAdmin）+ ユーザーメニュー。テナント切替は持ちません（常に全テナント横断）。このページ上部がライブのトップバーです。

識別
ロゴ横の ADMIN バッジで tenant-console と視覚的に区別。誤操作防止。
ユーザー
SuperAdmin 固定（紫バッジ）。OIDC クライアントは tenant-console と分離。
テナント切替なし
単一テナントに切り替える概念はなく、各画面が横断ビュー + テナント列で表現。
