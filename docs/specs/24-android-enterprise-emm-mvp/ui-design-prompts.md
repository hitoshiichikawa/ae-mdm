# UI Design — Claude Design 用プロンプト集（2フェーズ運用）

> [ui-design-brief.md](ui-design-brief.md) を Claude Design で使うための **貼ってすぐ使えるプロンプト**。
> 運用は2フェーズ: **① 全体構成を1回で確立 → ② その上で1画面ずつ**。各画面が同じデザインシステムを再利用するので、全体の一貫性が保てる。

---

## 使い方（流れ）

1. 本システムの Web は **tenant-console（顧客向け）** と **admin-console（運用向け）** の **2 つ**。まず **Phase 1A**（共通デザインシステム + tenant-console シェル）を1回投げて確立・確認し、admin-console に着手する際に **Phase 1B**（admin-console シェル）を投げる。
2. 確認できたら、**Phase 2 テンプレート**に画面仕様を差し込んで「1画面ずつ」投げる。毎回 Phase 1 の成果を再利用させる。
3. **1メッセージ = 1画面**。出力は shadcn/ui 語彙・日本語 UI・ライト/ダーク両対応・データ密 admin。
4. P1 の **デバイス一覧 → デバイス詳細 → エンロール** の順が動線として自然（記入済みプロンプトを下に用意）。

## Phase 1A — 全体構成プロンプト（共通デザインシステム + tenant-console シェル｜最初に1回）

```text
あなたは B2B SaaS 管理コンソールの UI デザイナーです。これから「Android Enterprise を使った
マルチテナント型 EMM/MDM の管理コンソール」を、複数回に分けて1画面ずつデザインしていきます。
このメッセージでは個別画面ではなく『全体構成（デザインシステム + アプリシェル + 共通コンポーネント）』
を確立してください。以降の画面はすべてここで決めたシステムを再利用します。

# プロダクト
- マルチテナント EMM SaaS の管理コンソール。利用者は顧客企業の IT 管理者。
- 端末を QR でエンロール → ポリシー配信 → 状態監視 → リモート LOCK/WIPE/REBOOT。
- トーン: 業務系・信頼感・データ密・誤操作防止。参照: Microsoft Intune / Jamf / Hexnode。

# 実装前提（この語彙で出力）
- React + TypeScript + Vite / Tailwind CSS / shadcn/ui。各 UI は shadcn/ui コンポーネントに対応づくこと。

# ビジュアル方向性
- アクセント: インディゴ系（primary）。ライト & ダーク 両対応（両モードで可読）。
- 密度: データ密な admin（コンパクト行・テーブル中心・13–14px 基調）。日本語 UI。
- フラット・クリーン。細い境界線(0.5–1px)・中庸の角丸(8–12px)。影は最小限（機能的フォーカス程度）。

# ロール（4種）
SuperAdmin / TenantAdmin / Operator / Viewer。ナビ・操作の出し分けに使う（詳細は各画面で指定）。

# この回の成果物（全体構成）
1. デザインシステム: カラートークンをライト/ダーク両方で定義
   - primary=インディゴ、背景/サーフェス/境界/テキスト、意味色 緑=成功/準拠・赤=危険/失敗/非準拠・
     琥珀=警告/同期遅延・灰=中立/未確認。タイポ階層・spacing・radius・border のトークン。
   - Tailwind / shadcn のテーマ変数として表現。
2. アプリシェル: 左サイドバー + トップバー
   - サイドバー項目（tenant-console）: ダッシュボード / デバイス / ポリシー / エンロール / アプリ / 監査ログ / 管理者　※「テナント」は含めない（admin-console 側）
   - トップバー: ページタイトル、現在ユーザー(email + ロールバッジ)、ユーザーメニュー（自テナント固定）
   - レスポンシブ（狭幅でサイドバー折りたたみ）。中央はコンテンツ領域（プレースホルダでよい）。
3. 共通コンポーネント・シート（以降の画面で再利用する部品）
   - ステータスバッジ（ラベルと色を固定）:
     - コンプライアンス: 準拠(緑)/非準拠(赤)/未確認(灰)/サポート対象外(淡灰)
     - 同期状態: 同期遅延(琥珀) ※コンプライアンスと併記しうる別指標
     - 管理モード: Fully Managed(青)/Dedicated (Kiosk)(紫)
     - コマンド状態: 実行待ち(淡灰)/成功(緑)/失敗(赤)/タイムアウト(琥珀)
     - テナント状態: バインド未完了(琥珀)/有効(緑)/無効(灰)
   - DataTable（密・ソート/フィルタ/行アクション）、メトリクスカード、空状態、ローディング(スケルトン)、
     エラー、403 権限拒否。
   - RoleGate: 権限のない操作ボタンは「非活性 + ツールチップで理由」、アクセス不可のナビ/画面ごとは「非表示」。
   - ConfirmDialog（二段階確認）: 不可逆操作（WIPE / テナント削除）用。対象名を明示し、名前入力 or
     二度目の明示確認を要求。危険色。
   - トースト: 非同期コマンドの送信フィードバック（実行待ち→成功/失敗）。
4. 上記を一覧できる「デザインシステム & コンポーネント・リファレンス」として提示してください
   （以降の各画面はこれを参照します）。

まず全体構成を提示してください。私が確認したら、次のメッセージから1画面ずつ依頼します。
```

### ⑥ ポリシー編集（5領域タブ）（§7.7）

```text
前のメッセージで確立したデザインシステム・アプリシェル・共通コンポーネントを再利用してください。
出力は shadcn/ui 語彙、日本語 UI、ライト/ダーク両対応、データ密 admin。アプリシェルの中にこの画面を
配置し、列挙した状態をすべて描いてください。

# 画面: ポリシー編集（/policies/:id, feature: policies）
- 目的: 1 ポリシーを 5 領域で編集する。複雑な構造化フォーム。
- 中心ロール / 可視性: TenantAdmin 以上。
- タブ（5 領域）と主要項目:
  1. アプリ管理 — 承認済みアプリの追加、インストール種別(FORCE_INSTALLED / AVAILABLE / BLOCKED / KIOSK)、
     権限既定。アプリ上限 3,000 件を超えると保存不可。
  2. パスワード — 品質 / 最小桁数 / 履歴 / 有効期限 / 失敗時挙動。
  3. セキュリティ — 暗号化、提供元不明アプリ、Play Protect、開発者設定、工場出荷リセット禁止 等。
  4. システム更新 — AUTOMATIC / WINDOWED(時間帯) / POSTPONE / KEEP_CURRENT、凍結期間。
  5. Kiosk — 単一 / 複数アプリ Kiosk、ステータスバー / ナビ / 電源ボタン制御（Dedicated 端末向け）。
- 主要アクション: 保存(upsert)、バリデーション、割当端末への配信プレビュー。
- 状態（すべて描く）: 編集中 / バリデーションエラー(不正値・上限超過を項目単位で表示) / 保存中 /
  保存成功 / 競合(バージョン) / 403。
- 構成要素（shadcn）: 共通ヘッダ(名前 / 保存ボタン)、Tabs(5 領域)、Form(RHF + Zod 前提)、
  各タブの Input / Select / Switch / RadioGroup、Alert(検証エラー)。
- 制約: 入力は管理者が理解できる日本語ラベルで（実装語彙そのままにしない）。Kiosk タブは Dedicated 端末向けの旨を補足。

この画面のみを、確立済みシステムに沿ってデザインしてください。
```

### ⑦ アプリ配信（Managed Play iframe）（§7.8）

```text
前のメッセージで確立したデザインシステム・アプリシェル・共通コンポーネントを再利用してください。
出力は shadcn/ui 語彙、日本語 UI、ライト/ダーク両対応、データ密 admin。アプリシェルの中にこの画面を
配置し、列挙した状態をすべて描いてください。

# 画面: アプリ配信（/apps, feature: apps）
- 目的: Managed Google Play でアプリを承認し、ポリシー経由で端末へ配信する。
- 中心ロール / 可視性: TenantAdmin 以上。
- 主要データ: 承認済みアプリカタログ(アイコン / 名称 / パッケージ名 / 承認日時)、各アプリのポリシー割当(強制 / 任意)。
- 主要アクション: Managed Google Play iframe を開いて承認 → カタログ反映、ポリシーへ FORCE_INSTALLED /
  AVAILABLE 割当、各端末のインストール状況参照。
- 状態（すべて描く）: 空(未承認 → 「アプリを追加」CTA) / カタログ表示 / iframe 表示中 / 同期中 / エラー。
- 構成要素（shadcn）: カタログ(カードグリッド or テーブル)、「アプリを追加」Button → iframe を Dialog / Sheet で
```
